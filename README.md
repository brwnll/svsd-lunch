# SVSD Lunch

The support and privacy policy pages for SVSD Lunch, an iPhone and iPad app with school lunch
menus for the Snoqualmie Valley School District. Published with GitHub Pages:

- https://brwnll.github.io/svsd-lunch/support/
- https://brwnll.github.io/svsd-lunch/privacy/

SVSD Lunch is an independent app by Small Dog Studios, LLC. It isn't made by, affiliated with or
endorsed by the Snoqualmie Valley School District.
